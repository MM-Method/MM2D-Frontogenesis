# MM2D
Benchmark of 2D Multi-Moment method for Frontogenesis problem


**Requirement**
1.Linux Operating System
2.gfortran
3.c-shell
4.GNU make


**How to compile**
1.Adapt the Makefile to your machine
2.Execute make


**Running the Benchmark**
1.Enter testcase folder
2.Adjust number of repeat run defined by "RUNS" in the benchmark script "run_benchmark.sh"
3.run the benchmark script


**Post-Process the wall clock time**
 1. Execute getcputime.csh  and the result will be documented in CPUTIME.txt
